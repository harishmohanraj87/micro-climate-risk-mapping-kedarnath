# Contributing

Contributions are welcome when they strengthen traceability, reproducibility, or scientific clarity.

Before submitting a change:

1. Describe whether the change is documentation, data preparation, analysis, modelling, or results reporting.
2. Do not add credentials, private records, personally identifiable information, or data that cannot be redistributed.
3. For external data, document provider, product/version, licence or terms, access date, processing steps, and restrictions.
4. For analysis code, provide a clear entry point, dependency changes, configuration, random seeds, and expected outputs.
5. For reported results, include the input version, split strategy, metrics, uncertainty, and command/configuration used to generate them. Do not overwrite or selectively omit unfavourable results.
6. Keep generated large files and trained artefacts out of version control unless they are essential, appropriately licensed, and reviewed.

Use descriptive commits and preserve the distinction between proposed methods, preliminary work, and validated findings.
